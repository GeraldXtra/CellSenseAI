# Test data

The seed phones in `server/data/phones.json` are our test data. We load them into the database with `npm run seed` from the `server` folder. That file is empty until we collect the phones. While we build the pages, `client/src/data/mockPhones.js` holds six sample phones, three sample reviews and a sample review summary in the exact shape the API returns. The table below records our test cases. We add the actual result and the pass or fail mark after we run each case.
